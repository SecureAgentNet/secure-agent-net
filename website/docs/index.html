Quick Start

SecureAgentNet (SAN) is a self-hosted gateway. Install the CLI, run the health check, register an agent, and route its first action through the ITCD pipeline.

zsh — secureagentnet — 80x24 content_copy
$ pip install secureagentnet
Installed console scripts: secureagentnet, san
$ san doctor
✓ Docker · ✓ Ollama · ✓ Redis · ✓ Vault — all checks passed
$ san agent register my-bot --type LangChain
[IDENTIFY] agent authenticated · trust 50
$ san run my-bot "python task.py"
✓ ALLOWED & EXECUTED · sandbox-0c03 · vault receipt issued
$

bolt Secure your existing tools

Wrap the tools you already have. Every invocation is routed through the ITCD pipeline — approved calls return their result, blocked calls return a policy message your agent can read.

code python — LangChain 
from secureagentnet.integrations.langchain import secure_tools

# every tool call now flows through Identify → Track → Contain → Decide
tools = secure_tools(my_tools)
agent = create_react_agent(llm, tools)
python — CrewAI
from secureagentnet.integrations.crewai import secure_tool

tool = secure_tool(tool)
python — AutoGen
from secureagentnet.integrations.autogen import secure_function

safe_fn = secure_function(my_tool)
