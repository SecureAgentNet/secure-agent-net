MCP / API Reference

FastAPI server on port 5000. All MCP routes under /api/v1/.

Authentication Flow

The MCP gateway uses challenge-response authentication. No permanent credentials are stored — agents prove identity with cryptographic signatures.

Step 1: Request Challenge

MethodPOST
Path/api/v1/auth/challenge
AuthNone
{ "public_key": "-----BEGIN PUBLIC KEY-----\nMIIB...\n-----END PUBLIC KEY-----" }

Returns a nonce (random 64-char hex string) and session_id.

Step 2: Sign and Login

MethodPOST
Path/api/v1/auth/login
AuthNone
{ "session_id": "abc123...", "signature": "a1b2c3d4..." // hex-encoded signature of the nonce }

Returns access_token (JWT), token_type: "bearer", expires_in: 3600.

Step 3: Token Refresh

MethodPOST
Path/api/v1/auth/refresh
AuthBearer <token>

Returns a new JWT with updated expiry.

Protected MCP Routes

All routes below require Authorization: Bearer <token>. The token is validated for expiry, signature, and agent existence/status.

List Tools

MethodGET
Path/api/v1/mcp/tools
{ "agent_id": "a1b2c3d4-...", "tools": [ {"name": "execute", "description": "Execute a shell command in a sandbox", "args": {"command": "string"}}, {"name": "read_file", "description": "Read a file from the sandbox", "args": {"path": "string"}}, {"name": "query", "description": "Query forensic event logs", "args": {"query": "string"}} ], "count": 3 }

Execute Tool

MethodPOST
Path/api/v1/mcp/execute
{ "action_name": "execute", "target_resource": "shell", "intent_summary": "List directory contents", "payload": {"command": "ls -la /tmp"} }

Runs through the full IDENTIFY → TRACK → DECIDE → CONTAIN pipeline. Returns execution result with Vault receipt.

Agent Info

MethodGET
Path/api/v1/mcp/agent

Returns the authenticated agent's identity, trust score, capabilities, and status.

Heartbeat

MethodPOST
Path/api/v1/mcp/heartbeat

Updates the agent's last_seen timestamp. Agents should ping every 30-60 seconds.

Capabilities

MethodGET
Path/api/v1/mcp/capabilities

Returns the authenticated agent's registered capabilities.
