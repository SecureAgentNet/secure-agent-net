CLI Reference

Two entry points: secureagentnet and san (alias).

System Commands

init

Initialize the SecureAgentNet system. Creates database, registers default admin agent.

$ secureagentnet init $ secureagentnet init --seed # Seed with test data $ secureagentnet init --mode minimal # Set deploy mode

doctor

System health check — verifies Python, Docker, Ollama, Redis, AppArmor, and database connectivity.

$ secureagentnet doctor $ secureagentnet doctor --deploy-mode local

version

$ secureagentnet version $ secureagentnet version --json

Agent Commands

agent register

$ secureagentnet agent register <name> $ secureagentnet agent register my-bot --type LangChain --desc "Web scraper" --capabilities read_file,search_web

agent list

$ secureagentnet agent list $ secureagentnet agent list --status active --json

agent get

$ secureagentnet agent get <agent-id-or-name>

agent update

$ secureagentnet agent update <id> --trust 75 --status suspended

agent revoke

$ secureagentnet agent revoke <id>

agent add-cap | capabilities

$ secureagentnet agent add-cap <id> execute_sql $ secureagentnet agent capabilities <id>

Pipeline Commands

run

Execute a command through the full ITCD pipeline with container sandboxing.

$ secureagentnet run <agent-id> <command> $ secureagentnet run my-agent "python script.py" --action execute --resource shell --json

evaluate

Test the DECIDE phase without container execution (no Docker needed).

$ secureagentnet evaluate "ls -la" $ secureagentnet evaluate "rm -rf /" --agent my-agent --intent "Testing dangerous command"

Forensics Commands

forensics query

$ secureagentnet forensics query --agent <id> $ secureagentnet forensics query --phase DECIDE --severity WARNING --limit 20

forensics timeline

$ secureagentnet forensics timeline <agent-id>

forensics verify

Verify a Vault audit log entry's integrity using Transit HMAC.

$ secureagentnet forensics verify vault-audit/agents/abc/log-123-v1

forensics summary

$ secureagentnet forensics summary --json

forensics export

$ secureagentnet forensics export --format csv

Security Commands

security status

$ secureagentnet security status

kill-switch active | activate | deactivate

$ secureagentnet kill-switch active $ secureagentnet kill-switch activate # Halts all agent operations $ secureagentnet kill-switch deactivate

circuit-breaker status

$ secureagentnet circuit-breaker status

security alerts

$ secureagentnet security alerts

Container Commands

contain provision

$ secureagentnet contain provision <agent-id> --cpu 2.0 --memory 1024

contain list | stop

$ secureagentnet contain list $ secureagentnet contain stop <container-id>

Other Commands

audit

$ secureagentnet audit --json

config show | set

$ secureagentnet config show $ secureagentnet config set deploy_mode local

metrics

$ secureagentnet metrics $ secureagentnet metrics --watch

server start | stop | status

$ secureagentnet server start --port 5000 $ secureagentnet server stop
