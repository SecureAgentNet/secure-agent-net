Phase Details

IDENTIFY

Verifies agent identity through challenge-response crypto, checks capability authorization against a registered whitelist, runs rogue detection (anomaly scoring on request patterns), checks circuit breaker state (per-agent failure tracking), and verifies the kill-switch is not active. IntentCapsule validates session-scoped goals and detects goal hijacking.

Components: IdentityRegistry, RogueDetector, CapabilityProfiler, CircuitBreaker, KillSwitchController, IntentCapsule.

TRACK

Captures the agent's intent before any decision is made, ensuring an audit trail even for blocked actions. ReasoningCaptureMiddleware wraps the DECIDE+CONTAIN callback — logs to Vault via AgentAuditor, with HMAC-SHA256 signing through Vault's Transit engine for tamper-proof verification.

Components: ReasoningCaptureMiddleware, AgentAuditor, VaultAuditClient (Transit + KV v2), LogIndexer, ForensicQueryEngine.

Docs: Phase2_Track.md

DECIDE

Three-tier evaluation:

  1. RuleFilter — deterministic rules: deny-list actions, dangerous paths, payload inspection. Loads policies from the database with hardcoded fallback.
  2. PiiRedactor — Microsoft Presidio with 6 recognizers sanitizes all data before it reaches the LLM. Fails-closed (deny) if unavailable.
  3. SemanticEvaluator — local Ollama LLM analyzes intent for prompt injection, goal hijacking, and data exfiltration. Retries with backoff, fail-closed on timeout.

Components: DecisionGateway, RuleFilter, PiiRedactor, SemanticEvaluator.

CONTAIN

Executes the command in an ephemeral Docker container with defense-in-depth:

  • seccomp — 76 allowed syscalls, all others blocked (SCMP_ACT_ERRNO)
  • AppArmor — denies /proc/sys, /sys, /boot, /root, /etc/shadow, raw sockets
  • Capabilities — all dropped (cap_drop: [ALL])
  • Root filesystem — read-only with tmpfs scratch (noexec, nosuid, nodev)
  • Network — disabled by default; configurable strict/moderate/permissive isolation
  • Limits — configurable CPU, memory, per-agent max (3), global max (10)
  • Metrics — CPU%, memory, network rx/tx collected from Docker stats API
  • OOM detection — reads State.OOMKilled from container inspect

Components: ContainerProvisioner, ResourceManager, NetworkIsolationConfig, SeccompProfileManager, AppArmorProfileManager.
