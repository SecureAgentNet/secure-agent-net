03 Contain — Kernel-Hardened Sandboxing

Each action runs inside an ephemeral container provisioned before the decision is made. With seccomp-bpf, AppArmor, a read-only root and no network by default, a compromised agent has nowhere to go.

  • verified_userseccomp + AppArmor syscall restriction

04 Decide — Tiered Policy Enforcement

A layered gateway makes the final call: fast rule filtering, AST drift checks, PII redaction, an LLM risk evaluation, and a human-in-the-loop gate for anything ambiguous. Denied actions never execute.
