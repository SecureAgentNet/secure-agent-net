Zero-Trust Security
for Autonomous AI Agents

Every action an AI agent takes flows through a 4-phase security pipeline: identify the agent, track its intent, evaluate the risk, and sandbox the execution. Nothing executes without passing all checks.

IDENTIFY
Verify identity, check capabilities, detect rogue behavior
→
TRACK
Capture intent to Vault with HMAC-signed audit trail
→
DECIDE
3-tier evaluation: rules → PII redaction → LLM analysis
→
CONTAIN
Docker sandbox with seccomp, AppArmor, read-only rootfs

Quick Start

From zero to evaluating agent actions in 60 seconds.

1
Install
$ pip install secureagentnet
2
Check your system
$ secureagentnet doctor SecureAgentNet System Health ================================================== ✓ Python 3.14.5 (3.10+ required) ✓ Platform: Linux ✓ Deploy Mode: docker ✓ Identity Registry: 0 agents registered ✓ Log Indexer: 0 events indexed ✓ Docker: Docker version 29.5.1 ✓ Ollama: ollama version is 0.24.0 ✓ Redis: connected ✓ Environment: development ╭────────────────────╮ │ All checks passed! │ ╰────────────────────╯

Initialize and evaluate

Deployment Modes

Scale from a quick local test to full production, without changing your code.

🔒 Docker (default)

Full security — container sandboxing, LLM evaluation, Redis rate limiting, Vault audit logging.

Docker Redis Ollama Vault
$ export DEPLOY_MODE=docker
$ secureagentnet init

💻 Local

Development mode — SQLite database, no Docker/Redis/Vault required.

Docker Redis Ollama Vault
$ export DEPLOY_MODE=local
$ secureagentnet init --mode local

⚡ Minimal

Zero dependencies — JSON file storage, no external services at all. Works on any OS instantly.

Docker Redis Ollama Vault
$ export DEPLOY_MODE=minimal
$ secureagentnet init --mode minimal

Key Features

Every layer of defense is independent. If one fails, the pipeline fails closed — never open.

🔐

Challenge-Response Auth

Agents prove identity by signing a cryptographic nonce with their Ed25519 or RSA private key. Short-lived JWTs issued on success.

📋

Tamper-Proof Audit Trail

Every agent intent is HMAC-signed via HashiCorp Vault Transit before execution. Verify integrity with forensics verify.

🧠

LLM Semantic Evaluation

Local Ollama models analyze agent intent for prompt injection, goal hijacking, and data exfiltration. PII is redacted by Microsoft Presidio before reaching the LLM.

📦

Docker Sandboxing

Commands execute in ephemeral containers with seccomp whitelisting, read-only rootfs, dropped capabilities, and network isolation.

⚡

Circuit Breaker & Kill Switch

Per-agent failure tracking auto-opens circuit breakers. System-wide kill switch halts all operations at the first sign of an attack.

🖥️

CLI-First, API-Ready

14 CLI subcommands for full control. FastAPI with JWT middleware for programmatic access. Optional Flask dashboard for visualization.

🌍

Cross-Platform

Runs on Linux, macOS, and Windows. Docker Desktop detection. Seccomp and AppArmor gracefully skipped on non-Linux hosts.

📊

Resource Metrics

Per-execution CPU, memory, and network usage collected from Docker stats API. OOM detection from container inspect.

🎯

Intent Scoping

IntentCapsule restricts agents to approved actions within a session. Goal-hijack detection blocks deviation from the original task.
