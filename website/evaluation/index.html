Red-team evaluation

Measured, not promised

Every number on this page is produced by running labelled corpora through the live decision gateway with real local-LLM calls, no mocks: 55 adversarial scenarios mapped to the OWASP LLM Top-10, 25 benign requests including deliberately borderline ones, and paired goal-hijacking probes. Results are reported as the mean and range over three independent runs.

The mandate is the mechanism, proven by ablation

SecureAgentNet's core claim is that anchoring every decision to the agent's commissioned mandate is what defeats goal hijacking without strangling legitimate work. To test that claim rather than assert it, the same corpora were run three ways: the full pipeline, the identical pipeline with mandates stripped, and static rules alone. The action text never changes. Only the security context does.

Without mandates, precision collapses

Strip the commissioned goals and the pipeline stays "safe" only by escalating 64% of legitimate work to a human, while goal-hijack detection falls from 6/6 to 3/6. The delta between columns is the measured contribution of commissioning.

Static rules alone catch 14.5%

The deterministic Tier-1 filter stops obvious dangerous patterns instantly and never blocks benign work, but it cannot see intent deviation. The remaining 82 points of detection are earned by mandate-anchored semantic evaluation.

Latency: a fast path and a careful path

Decisions resolve on two paths. Requests caught by deterministic rules return in single-digit milliseconds; requests that need semantic judgement pay a local-LLM round trip. Identical repeated actions are served from a TTL verdict cache, and the evaluation runs in a worker thread so one slow verdict never stalls other in-flight requests.

Fast path: rules & AST

~2 ms

Median decision time for requests resolved by Tier-1 rule filtering and AST drift checks. No model in the loop.

Semantic path: local LLM

~10 s

Median for requests requiring Tier-3 semantic evaluation on a local 3B model. Hardware and model dependent; cached verdicts return instantly.

What these numbers do and don't claim

  • Attacks are evaluated under a plausible cover mandate. They don't get flagged just for being uncommissioned, and benign agents carry their real production mandates, so the comparison is honest in both directions.
  • Escalation to a human is reported separately from denial. A request routed to review is a safety net, not a wrongful refusal, and it is never counted as a pass.
  • The LLM tier is non-deterministic, so metrics are reported as mean and range across runs. Attack scenarios are synthesised from the OWASP LLM Top-10 catalogue, and the benign corpus is small (25), so absolute numbers will vary with model, hardware, and corpus size.

Reproduce it yourself

The harness, corpora, and raw per-request results ship in the repository. One command re-runs the whole benchmark against your own hardware and model.

evaluation
$ python scripts/run_evaluation.py --runs 3
$ python scripts/run_evaluation.py --ablate-mandate
$ python scripts/run_evaluation.py --rule-only
