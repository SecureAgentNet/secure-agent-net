Get started

Install SecureAgentNet

SecureAgentNet is self-hosted: it runs entirely on your own infrastructure. Bring up the dependencies, verify the environment, and route your first agent action through the ITCD pipeline.

Prerequisites

Python 3.10+
Runs the SecureAgentNet gateway and CLI
Docker
Provisions the execution sandboxes
PostgreSQL + Redis
Audit store and shared state
HashiCorp Vault
Tamper-evident audit receipts
1

Clone & install

$ git clone https://github.com/SecureAgentNet/secure-agent-net.git && cd secure-agent-net && pip install -e .
Installed console scripts: secureagentnet, san
2

Start the dependencies

$ docker compose up -d vault redis postgres
securenet-vault, redis, postgres -- healthy
3

Verify the environment

$ san doctor
Docker, Ollama, Redis, Vault -- all checks passed
4

Register an agent

$ san agent register my-bot --type LangChain
[IDENTIFY] agent authenticated, trust 50
5

Run an action through ITCD

$ san run my-bot "python task.py"
ALLOWED & EXECUTED, sandbox-0c03, vault receipt issued
